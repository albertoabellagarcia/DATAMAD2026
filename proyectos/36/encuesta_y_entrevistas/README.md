# Encuesta y entrevistas

Lo que opinan los viajeros, para contrastar con los datos medidos.

- `crear_formulario.gs`: crea el Google Form (Apps Script: Nuevo proyecto, pegar, ejecutar `crearEncuesta`). Es anónimo y no recoge correo.
- `resultados_2026-11-25.md`: recuentos de las 109 respuestas hasta el 25/11 a las 14:48, generados con `resumen_encuesta.py`.
- `analisis_entrevistas.md`: 14 entrevistas en la calle del 24/11, resumidas sin nombres.

Las respuestas en bruto, los audios y las transcripciones no se suben: tienen textos libres y voces de personas que no han dado permiso para publicarlos.

Las dos fuentes son muestras de conveniencia, sobre todo de gente joven. Sirven para ilustrar el problema, no para medirlo; para medir están `analisis/` y `demo/fiabilidad.json`.
